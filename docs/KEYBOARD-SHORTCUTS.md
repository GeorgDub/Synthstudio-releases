# Synthstudio — Tastaturkürzel (Vollständige Referenz & manuelle Zuweisung)

> Ziel: **Alle** Funktionen in Synthstudio müssen manuell mit Tastaturkürzeln belegt werden können.

---

## Manuelles Shortcut-Zuweisung-System (Spezifikation)

### Öffnen des Shortcut-Editors
- `Strg + ,` (Einstellungen) → Tab **"Tastenkürzel"**
- Oder: Menü → **Bearbeiten → Tastenkürzel anpassen...**

### Zuweisung
1. Funktion in der Liste suchen oder per Suchfeld filtern
2. Auf das Shortcut-Feld klicken → `"Drücke eine Taste..."` erscheint
3. Gewünschte Tastenkombination drücken
4. Bei Konflikt: Warndialog mit Option zum Überschreiben
5. `Speichern` oder `Zurücksetzen auf Standard`

### Import/Export
- Shortcuts als `.json` exportieren und importieren
- Verschiedene Shortcut-Profile (z.B. "FL Studio", "Ableton", "Standard")

### 🎮 Computer-Keyboard als MIDI-Keyboard

Wenn die Piano Roll oder der Synthesizer aktiv ist, kann die Computer-Tastatur als MIDI-Keyboard verwendet werden:

```
Reihe: a s d f g h j k l ö ä
Töne:  C D E F G A H C D E F  (weiße Tasten)
       w e   t z u   o p
       C#D#  F#G#A#  C#D#      (schwarze Tasten)

Strg + Pfeil oben/unten: Oktave wechseln
Velocity: 100 (fest) oder via Shift-Taste (soft: 50)
```

## Shortcut-Konfigurations-Datei Format

```json
{
  "version": "1.0",
  "profile": "Standard",
  "shortcuts": {
    "transport.play": "Space",
    "transport.stop": "Ctrl+Space",
    "transport.record": "R",
    "transport.tapTempo": "T",
    "pattern.next": "Ctrl+ArrowRight",
    "pattern.prev": "Ctrl+ArrowLeft",
    "pianoroll.open": "P",
    "pianoroll.quantize": "Ctrl+Q",
    "mixer.open": "F9",
    "project.save": "Ctrl+S",
    "edit.undo": "Ctrl+Z",
    "edit.redo": "Ctrl+Y"
  }
}
```
